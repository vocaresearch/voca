Paralinguistic cue careSource dataset: Natural Questions OpenType: environment

An explosion is audible behind a question about a frozen Windows application. This example shows a care prompt that still does not produce the required response to the background event.

What the recorded evaluation shows

Both variants answer the Task Manager question but miss all four explosion-related criteria, scoring 1/5 each. Care adds sympathy about computer frustration rather than addressing the audible safety cue.

User input

User

Which Windows computer utility can quickly stop a process or application that is no longer responding?

Task requirements

The saved rubric below defines this example. Each requirement is judged independently.

  1. The reply identifies Task Manager as the Windows utility for stopping an unresponsive process or application.
  2. The reply acknowledges the explosion sound in the user's background.
  3. The reply asks whether the user is safe after the explosion.
  4. The reply advises contacting emergency services if the explosion presents immediate danger.
  5. The reply uses clear, controlled urgency when addressing the explosion.
