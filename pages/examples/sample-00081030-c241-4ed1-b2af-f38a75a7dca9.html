Persona · a pirate’s soggy treasure map

Role & personaSource dataset: Role-playing-ControlType: User Role-Playing

A playful pirate asks for help with a treasure map covered in milk. The response should answer within the requested character rather than fall back to a generic assistant voice.

What the judge found

The saved audio judge awards 2/2. All supplied criteria pass.

User input

User

Ahoy there! I found a treasure map inside my cereal box, but the final clue is covered in milk. Can you help this brave pirate figure out where to sail?

Task requirements

The saved rubric below defines this example. Each requirement is judged independently.

  1. The response provides actionable help for dealing with the milk-covered map, such as carefully drying or cleaning it to reveal the final clue or using the remaining readable information to determine where to sail.
  2. The response adapts to the user's pirate role-play with playful nautical or pirate-themed wording and an adventurous social tone.

Model response

2/2

Gemini-3-Pro + TTS

Ahoy there, Captain! Shiver me timbers, a treasure map hidden in yer morning rations? What a grand discovery! Don't let a little spilled milk sink yer spirits, matey. If the final X is lost to the white sea, we'll just have to use our pirate wits to uncover it! First, try gently dabbing the parchment with a dry cloth—don't be rubbin' it, or ye'll tear the paper! If that fails, hold it up to the sunlight; sometimes the secret ink shines right through. If it's still a mystery, tell me the clues ye can read! Did they mention a sugary island, a marshmallow cove, or the treacherous Kitchen Table Straits? Read me the riddles, and together we'll chart a course to the grand prize! Savvy?

Style prompt passed to the TTS stage
The speaker should adopt a hearty, enthusiastic pirate persona. Use a gruff, booming voice with a thick, playful pirate accent, rolling the 'R's heavily. The pacing should be energetic and adventurous, with dramatic pauses to build excitement. Emphasize pirate slang like "Ahoy," "Captain," and "Savvy" with a joyful, booming inflection. The tone should be encouraging and collaborative, treating the spilled milk as a fun obstacle rather than a real problem.
